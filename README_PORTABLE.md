# STM — Portable Package

## فایل‌های بستهٔ قابل حمل

| فایل | کاربرد |
|---|---|
| `first_run.bat` | **اول این را دوبار کلیک کن** — نصب + اجرا در یک مرحله |
| `setup.bat` | نصب یک‌باره (venv + requirements + دیتابیس) |
| `run.bat` | اجرای عادی برنامه (بعد از نصب) |

## مراحل انتقال به کامپیوتر دیگر

1. کل پوشهٔ `app/` را کپی کن (مثلاً روی فلش یا در پوشهٔ `C:\samane`)
2. **پوشهٔ `venv/` را حذف کن** (چون مخصوص این سیستم است)
3. مطمئن شو **Python 3.10+** روی کامپیوتر مقصد نصب است
4. روی `first_run.bat` دوبار کلیک کن

## نکات مهم

- **دیتابیس** در `data/app.db` ذخیره می‌شود. اگر می‌خواهی داده‌ها هم منتقل شوند، این فایل را نگه دار.
- **فایل‌های آپلودشده** در `data/uploads/` هستند.
- اگر ویندوز با خطای `Access denied` مواجه شد، پروژه را از `Program Files` بیرون بیاور.
- برای متوقف کردن سرور: در پنجرهٔ سیاه `Ctrl+C` بزن.

## پورت

سرور روی `http://127.0.0.1:5000` بالا می‌آید (فقط از همین کامپیوتر قابل دسترسی است).

## عیب‌یابی

### خطای `Python not found`
Python را از [python.org](https://python.org) نصب کن و گزینهٔ **Add to PATH** را حتماً تیک بزن.

### خطای `port 5000 already in use`
یک نسخهٔ دیگر برنامه در حال اجراست. Task Manager → python.exe را ببند.

### صفحهٔ مرورگر سفید است
`Ctrl+F5` بزن (پاک کردن کش).

### اگر دیتابیس خراب شد
فایل `data/app.db` را حذف کن، سپس `setup.bat` را دوباره اجرا کن.
